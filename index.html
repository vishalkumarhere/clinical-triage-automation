Triage Automation

An agent based automation pipeline, modeled on Epic Beacon style oncology infusion and referral workflows, that ingests incoming orders, auto classifies priority, flags missing prior authorization or scheduling conflicts, and drafts a structured review summary before an order ever reaches a staff queue.

All order, patient, and workflow figures on this page are illustrative synthetic data modeled on publicly described oncology infusion and referral scheduling workflows. No real order data, PHI, or Henry Ford Health or Epic data is used anywhere on this page.

→
2. Rules engineChecks prior auth status, insurance match, scheduling conflicts, and required order fields.
→
3. LLM summarizationRetrieves relevant protocol reference text and drafts a structured review summary per order.

→

What the automation catches
  • 01Missing prior authorization before it blocks scheduling. The rules engine checks auth status against payer rules at intake, not after the visit is already booked.
  • 02Scheduling conflicts across chair time and staffing. Flags an infusion order against projected chair capacity before it is confirmed.
  • 03Incomplete referral fields. Drafts a specific list of missing fields instead of a generic bounce back to the referring provider.
  • 04A structured summary staff can act on in seconds. Replaces reading the full raw order and chart note with a two line flag plus recommended next step.
